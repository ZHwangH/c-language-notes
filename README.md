## 提交规则（只有三条）

1. **每天一行代码也算数** —— 重要的是连续，不是量
2. **写不出来的题，也要提交**：把卡住的那一行注释掉，commit message 写「卡在 X」
3. **不追求正确** —— 错误的代码比没有代码有价值
